# Codex 启动提示词

你现在接手一个 Python 原型项目，目标是实现“港口至客户工厂全链路智能路径规划原型”。请先阅读本项目所有 `docs/*.md` 文件、`sample_data/*.csv` 文件和 `requirements.txt`。

## 项目目标

基于 CSV 台账数据，构建有向加权图，完成从北方港口到客户工厂的路径推断，输出：

1. 成本最低方案；
2. 时效最优方案；
3. 每条方案的分段费用和时效明细。

## 技术要求

- 使用 Python；
- 使用 pandas 读取 CSV；
- 使用 networkx 构建有向图并求最短路径；
- 使用 dataclasses 或 pydantic 定义数据结构；
- 第一阶段不使用数据库；
- 第一阶段不开发前端；
- 代码保持简单、可读、可解释。

## 业务规则

1. 散船费用支持指数测算和线下询价；
2. 指数测算公式：煤炭指数 × 1.12 + 2 + 5；
3. 铁路费用 = 始发站作业费 + 铁路运费 + 下站费 + 短途拖车费；
4. 敞顶箱需增加返篷布费用；
5. 客户无自建码头时，不能走客户自有码头路径；
6. 需要分别按费用和时效求最短路径。

## 开发方式

请先不要开发复杂接口。优先完成：

1. `src/models.py`；
2. `src/cost_rules.py`；
3. `src/io_utils.py`；
4. `src/graph_builder.py`；
5. `src/route_planner.py`；
6. `src/demo_run.py`。

每完成一个文件，请解释它的作用，并保证可以运行最小 demo。
