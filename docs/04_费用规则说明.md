# 04 费用规则说明

## 1. 散船费用

散船支持两种计价模式。

### 1.1 指数测算模式

```text
散船运费 = 煤炭指数 × 1.12 + 港驶费 2 元 + 利润 5 元
```

即：

```text
散船运费 = 煤炭指数 × 1.12 + 7
```

### 1.2 线下询价模式

业务人员直接录入线下询价价格，系统直接采用该价格。

注意：需要记录线下报价是否已经包含港驶费、利润或其他附加费用，避免重复计算。

## 2. 铁路费用

铁路费用应拆细为：

```text
铁路总费用 = 始发站作业费 + 铁路运费 + 下站费 + 短途拖车费 + 可选附加费
```

若为敞顶箱：

```text
可选附加费 = 返篷布费用
```

若不是敞顶箱：

```text
可选附加费 = 0
```

## 3. 汽运费用

第一阶段可先按台账或简单公式计算：

```text
汽运费用 = 公路距离 × 汽运单价
```

后续再补充最低收费、阶梯费率、区域差异等规则。

### 3.1 最后一公里汽运计费规则（2026-07-10 16:26 业务口径）

最后一公里汽运阶段需要先识别路线是否属于“既定路线库”。

#### 3.1.1 熟悉线路 / 既定路线

如果南港到客户工厂的路线已经在既定路线库中维护了确切运费，则直接采用既定运费。

要求：

- 既定路线必须能按“起点、终点、运输方式、包装方式、适用品种”等字段识别。
- 既定路线需要维护时间标签，例如 `维护日期` 或 `updated_at`。
- 同一路线多次维护运价时，以最新时间标签对应的记录为准。
- 采用既定运费时，仍需保留价格来源和维护时间，供结果解释使用。

#### 3.1.2 陌生路线 / 无既定运价记录

如果南港到客户工厂的路线没有既定运价记录，则按规则计费。

陌生路线距离来源：

```text
腾讯地图 API 公路路程数据
```

当前阶段仅记录该规则，不直接实现外部 API。后续实现时应将地图距离接口封装为独立 Provider，避免业务代码直接依赖外部 API。

#### 3.1.3 散粮汽运规则

设公路距离为 `X` 公里。

| 距离范围 | 计费规则 | 车型/说明 |
|---|---|---|
| `X <= 20` | 一口价 `15 元/吨` | 散粮 |
| `20 < X <= 30` | 一口价 `20 元/吨` | 散粮 |
| `30 < X <= 100` | `0.5 元/吨/公里 × X` | 自卸车 |
| `100 < X <= 150` | `0.4 元/吨/公里 × X` | 散粮自卸车 |
| `X > 150` | `0.3 元/吨/公里 × X` | 散粮高栏车 |

最终进入路径搜索的费用必须继续按订单吨数换算：

```text
该段总费用 = 单吨费用 × 订单吨数
```

#### 3.1.4 集装箱汽运规则

设公路距离为 `X` 公里，集装箱段费用为 `Y 元/箱`。

| 距离范围 | 计费规则 | 折合单吨 |
|---|---|---|
| `X <= 20` | `Y = 500 元/箱` | `Y / 30 元/吨` |
| `X > 20` | `Y = 500 - (X - 20) × 30 × 0.55 元/箱` | `Y / 30 元/吨` |

说明：

- 当前业务口径按 `30 吨/箱` 折算。
- 系统内部仍应优先保存原始单位 `元/箱` 和换算后的总费用。
- 上述 `X > 20` 公式会随距离增加而降低 `Y`，实现前需要业务侧再次确认公式方向是否正确；在确认前应作为待确认规则记录，不直接用于正式推荐。

## 4. 码头费用

码头相关费用包括：

- 码头作业费；
- 入库费；
- 直提费；
- 码头运输费；
- 短途拖车费。

当前会议口径中，到南港后倾向按入库费口径核算。该规则需领导最终确认。
