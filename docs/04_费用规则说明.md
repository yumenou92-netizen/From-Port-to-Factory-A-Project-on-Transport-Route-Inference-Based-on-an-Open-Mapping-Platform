# 04 费用规则说明

## 0. 当前代码入口

项目统一计费入口为 `src/cost_rules.py` 中的 `CostRuleEngine`。

- `FreightRate` 只承载运价数据，`evaluate_for_request()` 内部委托计费引擎。
- 所有有效结果统一输出 `CostCalculationResult.total_cost_yuan`。
- 结果保留 `rule_id`、`rule_version`、`calculation_detail` 和 `price_source`。
- 当前真实运价数据仅覆盖南港至客户工厂；北港至南港规则只做模型预留。
- 陌生汽运散粮和集装箱规则已登记为禁用配置，不能参与正式推荐。
- 最后一公里汽运已区分“熟悉路线”和“陌生路线”：熟悉路线通过维护运价计算；陌生路线当前只返回人工复核，不自动计费。

## 1. 散船费用

散船支持两种计价模式。

### 1.1 指数测算模式

```text
散船单位运费 = 煤炭指数 × 1.12 + 港驶费 2 元 + 利润 5 元
```

即：

```text
散船单位运费 = 煤炭指数 × 1.12 + 7
```

### 1.2 线下询价模式

业务人员直接录入线下询价价格，系统直接采用该价格。

注意：需要记录线下报价是否已经包含港驶费、利润或其他附加费用，避免重复计算。

## 2. 铁路费用

铁路费用应拆细为：

```text
铁路总费用 = 始发站作业费 + 铁路运费 + 下站费 + 短途拖车费 + 可选附加费
```

若为敞顶箱：

```text
可选附加费 = 返篷布费用
```

若不是敞顶箱：

```text
可选附加费 = 0
```

## 3. 汽运费用

此前“汽运费用 = 公路距离 × 汽运单价”的简单设计已不再作为正式规则使用。当前采用分层口径：

```text
先识别是否存在既定汽运运价
    ↓
有既定运价：直接使用维护运价，并按订单数量和费用单位换算为该段总费用
    ↓
无既定运价：进入陌生路线规则草案，但当前不自动计算
```

原因是最后一公里汽运费用受熟悉线路维护价、车型、距离分段、包装方式和公式确认状态影响，不能用单一 `距离 × 单价` 概括。

### 3.1 最后一公里汽运计费规则（2026-07-10 16:26 业务口径）

最后一公里汽运阶段需要先识别路线是否属于“既定路线库”。

#### 3.1.1 熟悉线路 / 既定路线

如果南港到客户工厂的路线已经在既定路线库中维护了确切运费，则直接采用既定运费。

要求：

- 既定路线必须能按“起点、终点、运输方式、包装方式、适用品种”等字段识别。
- 既定路线需要维护时间标签，例如 `维护日期` 或 `updated_at`。
- 同一路线多次维护运价时，以最新时间标签对应的记录为准。
- 采用既定运费时，仍需保留价格来源和维护时间，供结果解释使用。
- 当前代码入口为 `CostRuleEngine.calculate_last_mile_truck(..., known_rate=FreightRate)`。
- 有既定汽运运价时，结果规则编号为 `known_truck_maintained_rate`，计算过程会保留原始 `FreightRate` 计费规则。

#### 3.1.2 陌生路线 / 无既定运价记录

如果南港到客户工厂的路线没有既定运价记录，则理论上进入陌生路线规则草案。但当前阶段不自动计费，只返回人工复核。

陌生路线距离来源：

```text
腾讯地图 API 普通驾车路线公路距离和预估时间
```

当前阶段已经将腾讯地图接口封装为独立 Provider，但尚未把 API 结果接入陌生路线自动计费。默认使用普通驾车路线获取汽车行驶距离和预估时间；货车路线作为后续车辆限高、限重、限行场景的增强能力。业务代码不得直接依赖外部 API。

当前代码状态：

- `unknown_truck_bulk_distance_tier`：已按修订版算法登记为 `draft-2` 禁用草案。
- `unknown_truck_container_distance`：已登记为禁用草案。
- `TencentMapDrivingRouteProvider`：可通过本地环境变量 `TENCENT_MAP_API_KEY` 调用腾讯地图普通驾车路线，返回公里和小时。
- `TencentMapTruckingRouteProvider`：保留为未来可选增强，不作为当前主线依赖。
- `calculate_last_mile_truck()` 在无既定运价时返回 `manual_review`，不输出总费用。
- `calculate_edge_cost("last_mile_truck")` 仍不参与正式 `TransportEdge` 费用计算。

#### 3.1.3 散粮汽运规则

修订版规则文件：

```text
docs/最后一公里汽运计费规则算法设计_修订版.md
```

设实际驾车距离为 `x` 公里。修订后，阶梯函数计算的是“当前线路的单吨总运费”，单位为 `元/吨`，不是 `元/吨/公里`。

单吨运费函数为：

```text
0 < x <= 20       p(x) = 15
20 < x <= 30      p(x) = 20
30 < x <= 100     p(x) = 20 + (x - 30) * 0.7
100 < x <= 150    p(x) = 69 + (x - 100) * 0.6
150 < x <= 250    p(x) = 99 + (x - 150) * 0.5
x > 250           p(x) = 149 + (x - 250) * 0.3
```

总费用为：

```text
Y = p(x) × T
```

其中：

- `p(x)`：当前距离对应的单吨总运费，单位 `元/吨`；
- `T`：订单重量，单位 `吨`；
- `Y`：当前订单该汽运段总费用，单位 `元`。

禁止再乘一次距离：

```text
错误：Y = x × p(x) × T
```

边界参考：

| 距离 | 单吨运费 |
|---|---|
| `20 km` | `15 元/吨` |
| `30 km` | `20 元/吨` |
| `100 km` | `69 元/吨` |
| `150 km` | `99 元/吨` |
| `250 km` | `149 元/吨` |
| `300 km` | `164 元/吨` |

当前代码只登记上述分段参数，不启用自动计算。启用前必须完成：

- 最新运价选择器；
- DistanceProvider / DrivingRouteProvider 与计费规则正式集成；
- 业务验收；
- 阶梯边界单元测试；
- `TransportEdge` 可追溯输出。

#### 3.1.4 集装箱汽运规则

设公路距离为 `X` 公里，集装箱段费用为 `Y 元/箱`。

| 距离范围 | 待确认计费规则 | 当前状态 |
|---|---|---|
| `X <= 20` | `Y = 500 元/箱` | 已登记但禁用 |
| `X > 20` | `Y = 500 - (X - 20) × 30 × 0.55 元/箱` | 公式方向待确认，禁用 |

说明：

- 系统不自动进行吨、箱、柜之间的换算；订单数量单位必须与运价单位精确匹配。
- 系统内部保存原始单位，并仅在单位匹配时换算当前订单该段总费用。
- 上述 `X > 20` 公式会随距离增加而降低 `Y`，实现前需要业务侧再次确认公式方向是否正确；在确认前应作为待确认规则记录，不直接用于正式推荐。
- 修订版散粮规则不等同于集装箱规则；集装箱陌生线路仍保持禁用和待确认状态。

## 4. 码头费用

码头相关费用包括：

- 码头作业费；
- 入库费；
- 直提费；
- 码头运输费；
- 短途拖车费。

当前会议口径中，到南港后倾向按入库费口径核算。该规则需领导最终确认。
