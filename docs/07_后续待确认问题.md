# 07 后续待确认问题

## 1. 业务范围

1. 第一版是否只实现散船干线？
2. 铁路是否进入第一版路径排序，还是只做字段预留？
3. 集装箱是否完全后置？

## 2. 散船价格

1. 煤炭指数由谁录入？
2. 是否每日维护？
3. 线下询价是否包含港驶费和利润？
4. 线下询价是否有有效期？

## 3. 铁路规则

1. 铁路始发站和到站数据是否完整？
2. 始发站作业费、铁路运费、下站费、短途拖车费是否有台账？
3. 返篷布费用按线路、箱型还是统一标准？

## 4. 海运距离

1. 港口到港口海运里程从哪里来？
2. 是否有标准航线里程表？
3. 是否允许人工维护？

## 5. 最后一公里

1. 最近码头按直线距离、公路距离还是短途汽运费最低判断？
2. 客户自建码头数据是否完整？
3. 客户自建码头是否一定可接货？

## 6. 输出口径

1. 输出总价、单吨价还是两者都输出？
2. 估算价格是否允许参与推荐？
3. 是否需要标记价格来源？
