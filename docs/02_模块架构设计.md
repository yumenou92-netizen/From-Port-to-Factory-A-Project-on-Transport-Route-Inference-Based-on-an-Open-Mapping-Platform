# 02 模块架构设计

## 1. 总体架构

建议将原型拆为以下模块：

```text
数据读取层 → 数据模型层 → 费用规则层 → 路径生成/图构建层 → 最短路径搜索层 → 结果输出层
```

## 2. 模块说明

### 2.1 数据读取层

负责读取 CSV / Excel 数据，包括：

- 节点表；
- 运输边表；
- 客户表；
- 散船价格表；
- 铁路费用表；
- 码头费用表；
- 汽运费率表。

第一阶段建议只支持 CSV，减少环境复杂度。

### 2.2 数据模型层

建议定义以下对象：

- `Node`：运输节点；
- `Edge`：运输边；
- `Customer`：客户信息；
- `RouteSegment`：路径分段；
- `RouteResult`：路径方案结果。

可以使用 `dataclasses` 或 `pydantic`。

### 2.3 费用规则层

负责计算每条运输边的费用。至少包括：

- 散船费用；
- 铁路费用；
- 汽运费用；
- 码头费用。

### 2.4 路径生成 / 图构建层

将节点和边转为 `networkx.DiGraph`。

每条边至少带有：

- `mode`：运输方式；
- `cost`：费用权重；
- `time`：时效权重；
- `distance`：距离；
- `source`：费用来源；
- `available`：是否可用。

### 2.5 最短路径搜索层

使用 `networkx.shortest_path`：

- `weight='cost'`：成本最低；
- `weight='time'`：时效最优。

### 2.6 结果输出层

输出 JSON / CSV / Excel。每条路线必须拆成分段明细，而不能只输出节点列表。
