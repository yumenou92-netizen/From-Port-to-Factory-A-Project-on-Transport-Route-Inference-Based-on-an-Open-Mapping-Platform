# 05 数据结构设计

## 1. transport_nodes.csv

| 字段 | 含义 |
|---|---|
| node_id | 节点编号 |
| node_name | 节点名称 |
| node_type | 节点类型 |
| longitude | 经度 |
| latitude | 纬度 |
| region | 所属区域 |
| supported_modes | 支持运输方式 |
| is_active | 是否启用 |

## 2. transport_edges.csv

| 字段 | 含义 |
|---|---|
| edge_id | 边编号 |
| from_node_id | 起点节点 |
| to_node_id | 终点节点 |
| transport_mode | 运输方式 |
| distance | 距离 |
| distance_unit | 距离单位 |
| base_cost | 基础费用 |
| base_time | 基础时效 |
| cost_source | 费用来源 |
| rule_type | 费用规则类型 |
| is_active | 是否启用 |

## 3. customers.csv

| 字段 | 含义 |
|---|---|
| customer_id | 客户编号 |
| customer_name | 客户名称 |
| factory_longitude | 工厂经度 |
| factory_latitude | 工厂纬度 |
| address | 地址 |
| region | 所属区域 |
| has_private_terminal | 是否有自建码头 |
| private_terminal_id | 自建码头节点编号 |

## 4. bulk_shipping_prices.csv

| 字段 | 含义 |
|---|---|
| price_id | 价格编号 |
| date | 日期 |
| from_port_id | 起运港 |
| to_port_id | 到达港 |
| price_mode | index/manual |
| coal_index | 煤炭指数 |
| index_multiplier | 指数系数 |
| harbor_sailing_fee | 港驶费 |
| profit_fee | 利润 |
| manual_quote_price | 线下询价 |
| final_price | 最终价格 |

## 5. railway_fee_rules.csv

| 字段 | 含义 |
|---|---|
| rule_id | 规则编号 |
| origin_station_id | 铁路始发站 |
| destination_station_id | 铁路到站 |
| origin_operation_fee | 始发站作业费 |
| railway_freight_fee | 铁路运费 |
| destination_unloading_fee | 下站费 |
| short_truck_fee | 短途拖车费 |
| container_type | 箱型 |
| is_open_top_container | 是否敞顶箱 |
| tarpaulin_return_fee | 返篷布费用 |
| total_fee | 总费用 |
