# 03 算法与路径推断设计

## 1. 模型本质

底层可以理解为“加权边的有向图最短路径推断”。

- 节点：港口、码头、铁路站、客户工厂；
- 边：一段可运输关系；
- 方向：货物流向；
- 权重：费用 cost、时效 time。

但业务上不是纯数学最短路，还需要叠加业务规则过滤。

## 2. 路径推断流程

```text
输入订单与客户信息
        ↓
读取节点、边、费用台账
        ↓
根据客户标签过滤不可行边
        ↓
计算每条边的费用和时效
        ↓
构建有向加权图
        ↓
按 cost 求成本最低路径
        ↓
按 time 求时效最优路径
        ↓
拆解路径明细并输出
```

## 3. 业务规则过滤

示例规则：

1. 客户没有自建码头时，不能生成“客户自有码头直达”边；
2. 费用缺失的边不能参与正式推荐，除非标记为估算；
3. 散船价格可选择指数测算或线下询价；
4. 铁路敞顶箱需要增加返篷布费用；
5. 海运、公路、铁路距离来源不同，不能混用。

## 4. 最短路径目标

至少运行两次：

```python
cost_path = nx.shortest_path(G, source=start, target=end, weight="cost")
time_path = nx.shortest_path(G, source=start, target=end, weight="time")
```
