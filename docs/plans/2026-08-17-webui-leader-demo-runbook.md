# WebUI 领导展示运行手册

## 展示边界

- 本页面当前展示已接入的 **散粮、内贸、玉米/小麦** 路径规划链路。
- 北港至南港采用真实散船运价、确认的航运总时效和南港码头作业费；南港至客户工厂可比较直接汽运或已满足准入条件的驳船中转方案。
- 费用最低与时间最短分别独立搜索；页面不构造综合权重。
- `AdditionalFee` 仅加载，不在适用条件未确认时计入；客户无自有码头是明确的 `demo_placeholder` 画像。
- 地图中散船/驳船是维护控制点形成的航线示意，汽运是同次腾讯道路请求返回的折线。它们不是生产调度航线或 AIS 轨迹。

## 启动

在项目根目录 PowerShell 执行：

```powershell
.\scripts\start_leader_web_demo.ps1
```

脚本优先使用本地领导确认修订副本；副本不存在时自动使用当前维护的
`运费数据.xlsx`，并启动到：

```text
http://127.0.0.1:8765
```

如 PyCharm 使用独立解释器：

```powershell
.\scripts\start_leader_web_demo.ps1 -PythonExe "D:\path\to\python.exe"
```

需要显式指定其他本地工作簿时：

```powershell
.\scripts\start_leader_web_demo.ps1 -FreightWorkbookPath "D:\path\to\运费数据.xlsx"
```

服务窗口保持打开；展示结束后按 `Ctrl+C` 停止。页面只绑定 `127.0.0.1`，不对局域网开放。

## 展示顺序

1. 先说明左侧输入只开放当前已验证的订单范围；“指定南港”留空时由模型自动筛选。
2. 运行案例 A，先看双目标结果卡的总费用、总时效、折合单价和费用组成，再点击两张路线卡切换地图重点路线。
3. 点击“展开明细”，按需展示候选南港准入、入图边数、数据来源和运行提示；不逐条展开无关候选。
4. 运行案例 B，填写指定南港，说明人工指定会缩小为该南港的完整路径测算，而不是绕过计费或构图规则。
5. 结束时回到数据边界：地图与 Web 是已有应用服务的展示层，候选、费用、时间和双目标搜索仍由同一后端主链生成。

## 展示前 3 分钟检查

- 浏览器打开 `http://127.0.0.1:8765`，右上角显示“本地模型已连接”。
- 腾讯底图正常加载；若没有加载，先确认本地腾讯 JavaScript API 权限、网络和 Key 配置。模型结果不依赖底图，但领导展示建议先解决。
- 运行案例 A 一次，确认地图出现水运虚线、道路折线与节点标记。
- 不展示 API Key、本地绝对路径、原始运价表、全部候选告警或浏览器开发者工具。

## 现场故障口径

- **“地点坐标未确认”**：输入名称未命中本地节点且腾讯地点检索未返回可用坐标；改用已维护全称或检查网络。
- **“本次未形成搜索图”**：表示当前订单下没有同时满足能力、费用、时间、节点和运价准入的数据边；不是将缺失数据默认按零处理。
- **地图未加载但有结果**：地图 JavaScript 底图故障，不影响后端路线计算；可展示结果卡和运行信息。
- **费用最低与时间最短相同**：是本次候选范围内两次独立搜索得到了同一路线，不是把两个目标合并成了一个分数。
