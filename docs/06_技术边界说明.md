# 06 技术边界说明

## 1. 当前个人能力边界

当前开发者为交通工程方向研一实习生，并非专业软件开发工程师。具备以下能力：

- 理解交通运输链条；
- 拆解运输方式和费用结构；
- 设计概念级节点、边、权重模型；
- 使用简单加权图最短路径思想；
- 在 Codex 辅助下编写 Python 原型。

但不具备以下经验：

- 商业级最短路径系统开发；
- 生产数据库设计；
- 前端开发；
- 后端接口部署；
- 高并发服务；
- 企业级系统运维。

## 2. 当前项目定位

本工程应定位为：

```text
需求澄清 + 交通运输业务建模 + Python 原型验证
```

而不是：

```text
正式商业级路径规划系统
```

## 3. Codex 使用原则

Codex 可用于辅助：

- 生成 Python 原型代码；
- 补全函数；
- 重构模块；
- 编写测试；
- 生成 README；
- 修复运行错误。

但 Codex 生成的代码必须人工检查，不应直接作为生产系统代码。
